# Abdelrahman Elshrief

Personal site. Computer Engineering at the University of Toronto.

Quiet layout, cream/Nile palette, a few Egyptian details if you look.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit content

- `content/site.ts` — name, bio, links
- `content/experience.ts` — roles and dialog bullets
- `content/projects.ts` — project list
- `content/writing.ts` — writing index
- `app/writing/(post)/<slug>/page.mdx` — a post
- `public/resume.pdf` — resume download

## Deploy

Vercel. Set `NEXT_PUBLIC_SITE_URL` to the production origin once you have a domain.
